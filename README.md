# ⚡ Company System Database

> “A system is only as strong as the database behind it.”

A practical SQL project built to apply real Database Design concepts and strengthen my understanding of SQL fundamentals using MySQL.

This project simulates a simple company management system where departments, staff members, projects, and employee-project relationships are connected through a relational database structure.

Instead of focusing only on writing queries, this project focuses on understanding:
- How data is organized
- How relationships are designed
- How databases behave in real systems
- And how SQL becomes a way of thinking, not just syntax

# 🏗️ Database Structure

The system contains multiple connected entities:

- **Department**
- **Staff**
- **Project**
- **Works_On**

The `Works_On` table represents a Many-to-Many relationship between staff members and projects.
